## What the column finds

- **J1. In eval code, this engine's compiler leaves many `semantics` rows unchecked.** Of the rows its `Visit*` methods
  check, the super rows of a method, of a function or generator's body or parameters holding a super property, and of a
  constructor with no heritage, and `arguments` in a field initialiser, are refused in none of the probes' three forms,
  since the checks skip direct-eval code, which an indirect eval's code also is; as a Script each is refused before any
  code runs. `arguments` in a static block and `this` as a for-in target are refused nowhere, as a Script either. They are the rule's class T and C1, listed by row before any
  run. Decision D64's second half ("at SJL-15 for the rest") is applied to them.
- **J2. In eval code, three kinds of row are refused with the wrong error, or not answered.** A super call in a function's, generator's or async
  function's parameters or body is an `Error` from a .NET `ArgumentNullException`; a field initialiser holding a super
  call, inside a function, is compiled without end; a static block's super call is a run-time `TypeError`. Each is a
  correction of Broiler.JS (C1), and a hang and an engine exception are defects beside the specification, which the
  model's early refusal ends.
- **J3. Two facts are wrong in a completion value**: a closure in the parameters sees the body's `var` (FF4), and an
  arrow's direct eval declares its `var` in the enclosing function (FF5). Both are corrections of Broiler.JS that reading
  the model's facts makes.
- **J4. Named evaluation is missing in indirect-eval code** in three of the probes' forms (NE1); as Scripts the
  `semantics` vectors' first runs show every name given, and so do revision 43's three forms in a direct eval's code.
- **J5. Free names and captures have one producer**, this engine's `FreeNameScan`, as JSD-0088's X1 records: the model's
  fact is an extraction from it.
- **J6. Broiler.VM's Annex B differs in three inputs of eval code** (AB1), one of which, the block function named
  `arguments`, is the pinned edition against test262 at `ccaac100`, and the only one a Script shows; the `semantics`
  vector that holds it follows the pinned edition and says so.
- **J7. Broiler.VM's timing of eval code's private names** (its F6) is not shown by these probes: its executor refuses the
  eval code before any of it runs.
