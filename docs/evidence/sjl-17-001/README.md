- **[`invariant-probe.expected.txt`](invariant-probe.expected.txt)** is the reference's answer for the locale this
  engine's available-locale policy resolves under invariant globalization (JSD-0082 decision D7): the available
  locales are `en-US` and `en`, so a request whose language is `en` keeps its tag and every other request resolves to
  the default, `en-US`, and is answered by the root collation. It was written on 2026-11-01 by the reference bundle
  `sjl-9-001`'s [`reference.txt`](../sjl-9-001/reference.txt) names, Node.js v26.12.0 (ICU 78.3, CLDR 48.0), whose
  tarball was retrieved into its own directory and matched the digest that file records, with `TZ=UTC` and no `LANG`,
  by this driver, each collator made for the locale the policy resolves:

  ```js
  // node expected-driver.js invariant-probe.js > invariant-probe.expected.txt
  const fs = require('fs');
  const Real = Intl.Collator, realCompare = String.prototype.localeCompare;
  function policy(locales) {
    const tag = locales === undefined ? undefined : String(locales);
    return tag !== undefined && /^en(-|$)/.test(tag) ? tag : 'en-US';
  }
  function Collator(locales, options) { return new Real(policy(locales), options); }
  Intl.Collator = Collator;
  String.prototype.localeCompare = function (that, locales, options) { return realCompare.call(this, that, policy(locales), options); };
  globalThis.print = (s) => process.stdout.write(s + '\n');
  (0, eval)(fs.readFileSync(process.argv[2], 'utf8'));
  ```

  Two further runs bear on the file, and neither is part C's: Broiler.VM's conformance root, with each request

  `o14b-invariant-probe-policy`), so the shared collator, which is Broiler.VM's (decision E2), can meet it; and this

## What the rule takes from SJL-17's plan, and where it departs

The rule is the plan's text, with the record's numbers filled in, and three changes that records filed since the plan
was written require:
- **Part A** names `test/intl402/Locale/prototype/getCollations/output-array-values.js`, which keeps its base verdict:

- **Part B** reads the `orderings` program "with its retained answer, and its divergences file if that commit holds
  one", where the plan read "with its retained answer and divergences file": the program has none at Broiler.VM
  `83290f9`, whose `src/tests/cldr/orderings/` the commit that carries Broiler.VM's own bundle `sjl-17-001` rule
  leaves unchanged (finding F3). The rule's parenthetical names `83290f9` as the commit where that was read, not as
  the commit whose files are the population.
- **Part C** cites the available-locale policy as JSD-0082's decision D7, where the plan read "JSD-0081 decision D7",
  which is the regular-expression nesting limit (finding F5).
