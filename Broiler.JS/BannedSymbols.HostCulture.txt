# Milestone SJL-9's clause 8, "Host globalization remains only behind the optional providers", held by the build on the
# owner's ruling of 2026-11-11, "Fix all + enforce". Broiler.JS/Directory.Build.props hands this list to the banned-API
# analyzer (RS0030, an error by host-culture.globalconfig) in the engine's product projects, beside the five globalization
# rules. Those rules make a call that names no culture an error; they accept a call that names the host's culture. This
# list closes that gap: each entry reads the host's culture, or builds a .NET culture from the host's data, by name, and
# only the kept paths the ruling names may use one, each with "#pragma warning disable RS0030" and its reason in place.
# A method is named with its parameters, overload by overload: the analyzer bans no overload a name without them gives.
# The kept paths: the default-locale provider (decision D7), the host-culture provider (decision D6), SJL-D-17's .NET
# format strings of toLocaleString and its legacy Date.parse, and Intl.Collator's comparison until milestone SJL-17.
