# Node 22's DurationFormat predates the current draft (13 DurationFormat Objects) in seven ways, and
# each line below shows one or more of them. In the draft:
# - only the first unit written carries the sign; every later unit is formatted with signDisplay
#   'never' (13.5.15 PartitionDurationFormatPattern, 13.5.12 FormatNumericUnits), and a negative
#   duration's first unit is -0 where its value is 0;
# - a clock (numeric or 2-digit units) is one element of the unit list, so a written unit before it
#   is followed by the list's separator, not by a time separator (13.5.15, 13.5.14 ListFormatParts);
# - seconds after numeric minutes are 2-digit and displayed always, so 5 minutes is 5:00 (13.5.6
#   GetDurationUnitOptions);
# - a clock's numbers are not grouped, useGrouping false (13.5.9 to 13.5.11);
# - fractions are truncated, roundingMode 'trunc', so 7.008 seconds to two digits is 7.00 (13.5.11,
#   13.5.15);
# - a fractional unit displayed 'always', and a word style after a numeric unit, are RangeErrors
#   (13.5.6.2 ValidateDurationUnitStyle), and years of 2^32 or more are a RangeError (13.5.5
#   IsValidDuration);
# - resolvedOptions writes numberingSystem second, after locale (13.3.2, table 21).
