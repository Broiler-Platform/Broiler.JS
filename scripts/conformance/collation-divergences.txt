# The collation vectors' classified differences, read by generate_collation_vectors.py.
#
# A line `reason <key>: <text>` defines a reason. A line `<engine> <key> <id>` classifies the vector <id> as a
# divergence of <engine> for that reason: the generator writes the field divergence.<engine>: <text>. A normative
# vector becomes a divergence. An impl-defined one stays impl-defined: its per-engine.<engine> field is the
# expectation that engine's own data gives, which the vector's case states, and the divergence field says the engine
# does not meet it (SCHEMA.md section 5). The generator refuses an impl-defined vector classified for an engine its
# case states no expectation for. The vector's expected value never changes.
#
# A line is added in a new corpus revision, with a dated row in conformance/vectors/REVISIONS.md, and is removed only
# the same way, when the engine's cut-over corrects the difference and lists the correction. Every reason names the
# row of bundle sjl-17-001's correspondence from code (Broiler.VM's docs/evidence/sjl-17-001/correspondence.md) whose
# answer the engine gives in the difference, which is one of the rows the vector's note names, the engine's answer as
# that row records it, the class JSD-0084 gives the row, and the work package that answers it: SJL-17.5, Broiler.JS's
# cut-over to the shared collator, or SJL-17.3's data decision. A reason quotes the row's cells shortened (" ..."
# marks a cut) and in ASCII (U+XXXX for any other character).
#
# Revision 34, 2026-11-02: every difference of Broiler.JS's first engine-level run on the collation vectors, at
# revision 33 (d85da200), under TZ=UTC with the invariant culture, on one host, Ubuntu 24.04.5 with ICU 74.2
# (libicu74 74.2-1ubuntu3.1), the host's ICU whose CompareInfo this engine's Intl.Collator reads, so that the
# classification is of that host and a host with another ICU is not read. Broiler.VM's first run, taken at b43d0bb
# from a scratch archive of revision 33, has no difference on the area, so no line names it. The runs are retained in
# docs/evidence/sjl-17-001/engine/.
#

# asked the pair directly, through its C API (ucol_strcoll over the root collator, normalization on, tertiary

# maxVariable punctuation, the settings the file's own test takes). Where it answers as Broiler.JS does, the
# difference is the host's data, row O2; where it answers as the reference does, and Broiler.JS does not, the
# difference is Broiler.JS's mapping of ignorePunctuation onto IgnoreSymbols, row O5a. Every pair was one or the
# other. An ignorePunctuation vector is row O5b's where the option is false (a space against NBSP at base) and row
