# The Date area's classified differences, read by generate_date_vectors.py.
#
# A line `reason <key>: <text>` defines a reason. A line `<engine> <key> <id>` classifies the vector
# <id> as a divergence of <engine> for that reason: the generator writes the field
# divergence.<engine>: <text>, and a normative vector becomes a divergence. An impl-defined vector
# stays impl-defined, the field classifying the engine's difference from its own per-engine
# expectation. The vector's expected value never changes (SCHEMA.md section 5).
#
# A line is added in a new corpus revision, with a dated row in conformance/vectors/REVISIONS.md,
# and is removed only the same way, when the engine's cut-over corrects the difference and lists
# the correction. Every reason names the plan that answers it and the row of bundle sjl-6-001's
# correspondence from code (Broiler.VM's docs/evidence/sjl-6-001/correspondence.md) it confirms.
#
# Revision 15, 2026-10-15: every difference of each engine's first engine-level run on the Date area,

# 1,016 of Broiler.JS's, run in America/New_York, of which 65 also differ under UTC, and 16 of
# Broiler.VM's. A Broiler.JS vector of reason js-date-only-local or js-offset-mixed matches under UTC,
# where its run reports the divergence as no longer holding; the rule of this repository's bundle
# sjl-6-001 runs the area in both zones.
