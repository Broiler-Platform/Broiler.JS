# The Intl area's classified differences, read by generate_intl_vectors.py.
#
# A line `reason <key>: <text>` defines a reason. A line `<engine> <key> <id>` classifies the vector <id> as a
# divergence of <engine> for that reason: the generator writes the field divergence.<engine>: <text>. A normative
# vector becomes a divergence. An impl-defined one stays impl-defined: its per-engine.<engine> field is the
# expectation that engine's plan commits it to, which the vector's case states, and the divergence field says the
# engine does not meet it yet (SCHEMA.md section 5). The generator refuses an impl-defined vector classified for an
# engine its case states no expectation for. The vector's expected value never changes.
#
# A line is added in a new corpus revision, with a dated row in conformance/vectors/REVISIONS.md, and is removed only
# the same way, when the engine's cut-over corrects the difference and lists the correction. Every reason names the
# row of bundle sjl-9-001's correspondence from code (Broiler.VM's docs/evidence/sjl-9-001/correspondence.md) it
# confirms, the engine's answer as that row records it, the class JSD-0082 gives the row, and the work package that
# answers it: SJL-9.5, Broiler.JS's cut-over to the shared Intl library, or SJL-9.4, Broiler.VM's. A difference is
# classified under the row whose answer the engine gives in it, which is one of the rows the vector's note names, and
# not under every row the vector reaches. A reason quotes the row's cells shortened (" ..." marks a cut) and in ASCII
# (U+XXXX for any other character).
