# The number area's classified differences, read by generate_number_vectors.py.
#
# A line `reason <key>: <text>` defines a reason. A line `<engine> <key> <id>` classifies the vector
# <id> as a divergence of <engine> for that reason: the generator writes the vector with class
# divergence and the field divergence.<engine>: <text>. The vector's expected value never changes;
# a divergence is a classified difference, not an expectation (SCHEMA.md section 5).
#
# A line is added in a new corpus revision, with a dated row in conformance/vectors/REVISIONS.md,
# and is removed only the same way, when the engine's cut-over corrects the difference and lists
# the correction in its changelog. Every reason names the plan that answers it.
#
# Revision 2, 2026-10-12: every difference of Broiler.JS's first engine-level run, on revision 1.
# Revision 3, 2026-10-12: every difference of Broiler.VM's first engine-level run, on revision 2.
# Revision 5, 2026-10-12: Broiler.JS's cut-over (milestone SJL-3.5) corrects 696 of its 700 divergences,
# whose lines and now unused reasons are removed; docs/evidence/sjl-3-001/engine/retired-divergences.tsv
# lists them.
# Revision 6, 2026-10-13: Broiler.VM's cut-over (milestone SJL-3.4) corrects all 391 of its divergences,
# whose lines and reasons are removed; docs/evidence/sjl-4-001/engine/retired-divergences.tsv lists them.
