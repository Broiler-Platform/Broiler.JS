# The Temporal area's classified differences, read by generate_temporal_vectors.py.
#
# A line `reason <key>: <text>` defines a reason. A line `<engine> <key> <id>` classifies the vector
# <id> as a divergence of <engine> for that reason: the generator writes the field
# divergence.<engine>: <text>, and a normative vector becomes a divergence. The vector's expected
# value never changes (SCHEMA.md section 5).
#
# A line is added in a new corpus revision, with a dated row in conformance/vectors/REVISIONS.md,
# and is removed only the same way, when the engine's cut-over corrects the difference and lists
# the correction. Every reason names the row of bundle sjl-10-001's correspondence from code
# (Broiler.VM's docs/evidence/sjl-10-001/correspondence.md) it confirms, the class JSD-0078 gives it
# (each is a correction), and the work package that answers it: SJL-10.5, this engine's cut-over to
# the shared Temporal core, or SJL-10.4, Broiler.VM's.
#

# whose reports are byte for byte the same, and every difference of Broiler.VM's first run, taken
# locally from a scratch archive of revision 24 (the same directory, broiler-vm-*).
