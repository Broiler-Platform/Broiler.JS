# broiler-js intl locale list 1: Broiler.JS's embedding
#
# Decision D5 of Broiler.VM's JSD-0082 (milestone SJL-9.1 of the shared JavaScript libraries
# programme), as this repository's plan records it in docs/roadmap/SharedLibraries.md, "Area
# verdicts", "Locale data and the Intl algorithms (SJL-9.1)", "Decision D5's two lists", list 2.
# Broiler.JS's main data is the union of four sources:
#   1. the languages Broiler.Unicode.Cldr.LocaleData serves today: ar, de, en, es, fr, it, ja, ko,
#      nl, pl, pt, ru, sv, tr, zh, each also named by source 2;
#   2. every locale the intl402 files passing at its base and the reference datasets name, bundle
#      sjl-9-001's locales/union.tsv: the languages CLDR 48.2.0 carries main data for, each under
#      its CLDR name (aar as aa, ces as cs, tl as fil, iw and heb as he, in as id, mo as ro, sh and
#      cnr as sr, ji as yi, cmn as zh), and the named locales that are CLDR 48.2.0 locales in their
#      own right, in availableLocales.json or defaultContent.json;
#   3. en-US, the default-locale provider's fallback (decision D7);
#   4. und.
# The languages union.tsv names that CLDR carries no main data for (aae, art, ary, cel, hak, hsn,
# hyw, sgn) and the base names that are no CLDR locale (zh-TW and the rest) add nothing here: their
# tests read the global alias and likely-subtags tables, and the library resolves them as any tag.
#
# RE-RUN BEFORE GENERATION (JSD-0082, Context; finding F17). On 2026-10-26, before any table was
# generated, scripts/intl/enumerate_locales.py ran again on the newest valid UTC whole-suite report
# with negative tests of this repository's default branch, bundle sjl-12-001's after/part-a report
# (run 40231802611 at c29d653f), with test262 ccaac100 and Broiler.VM 4cf9ca44's datasets and pin:
# every row of union.tsv, intl402.tsv, datasets.tsv and uncounted.tsv equalled the committed one,
# so the list stands.
#
# `locale <tag> main` marks a locale whose own CLDR main data is written: a tag cldr-core's
# availableLocales.json names among its `full` locales, und, root, among them. A `locale <tag>`
# without it is one of CLDR's default-content locales, which reads its data through its parent.
# `supplemental *`: the plural, ordinal, plural-range and day-period tables cover every language
# CLDR states rules for, and the global tables are as Broiler.VM's. Ordinal order, each tag once.
# Broiler.ECMAScript.Generation's IntlLocaleList reads this text. Each later addition is a dated
# data decision with its measured size.
